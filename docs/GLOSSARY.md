# Glossar

| Begriff oder Symbol | Bedeutung im RPF-Projekt |
| --- | --- |
| RPF | Referenzpunkt-Funktion |
| RPF-0 | Basiskern: Ereignis → Stopp → Selbstkalibrierung → Interpretation → Handlung |
| RPF-3 | Kurzschnitt Stopp → Kalibrieren → Interpretieren mit den Erweiterungen von v1.2 |
| RPF-X | Reflexivitätsmodul der RPF |
| IR | introspektive Reaktivität |
| Referenzpunkt | expliziter Prüfpunkt zwischen Ereignis und Interpretation |
| Referenzrahmen | Ebene, auf der eine Aussage oder ein Konflikt eingeordnet wird |
| `C_i` | interne Konfidenz einer Interpretation |
| `C_e` | Stärke externer Evidenz für eine Interpretation |
| `ΔK` | marginaler Informations- oder Erkenntniszuwachs einer RPF-Iteration |
| `ε` | minimale relevante Zuwachsschwelle |
| `n_max` | maximale Zahl von RPF-Iterationen |
| `T_max` | maximales Zeitbudget |
| `B_min` | minimale verbleibende Ressource, bei der terminiert wird |
| `O_desc` | Beobachtungsoperator: Beschreibung |
| `O_eval` | Beobachtungsoperator: Bewertung |
| `O_control` | Beobachtungsoperator: Begrenzung |
| `O_cal` | Beobachtungsoperator: Kalibrierung |
| `ΔI_O` | marginaler Informationsgewinn einer Beobachtungsiteration |
| `A_O` | durch Beobachtung ausgelöste Aktivierung oder Belastung |
| `θ_A` | Abbruchschwelle für `A_O` |
| `IDLE` | inaktiver Transit- und Bereitschaftszustand |
| `ISOLATION` | Trennung des Ereignisses von der Erstinterpretation |
| `OPERATOR_APPL` | epistemische Operatoranwendung |
| `DELTA_EVAL` | Prüfung von Informationszuwachs und Abbruchbedingungen |
| `HYPOTHESIS_GEN` | Erzeugung prüfbarer Interpretationshypothesen |
| `ADAPTIVE_VAL` | Bewertung über mehrere Zeithorizonte |
| `OUTPUT_INTERFACE` | strukturierte Ausgabe von Ergebnis und Unsicherheit |
| `DELEGIERT` | Abschluss wegen unzureichender Kompetenz oder Evidenz |
| `NO_REFERENCE` | Abschluss ohne belastbar bestimmbaren Referenzpunkt |
| Frozen Draft | eingefrorener Entwurf, der nicht stillschweigend überschrieben wird |
| IDLE | keine aktive Revision; Warten auf neue dokumentierte Revision oder Evidenz |
